# 생성형 AI의 ‘계층형 심리 구조’ 설계: Protofelix LayerAI 모델의 기술적 이점, 위험, 구현·평가 프레임워크

**Author:** E(on). Jun  
**Publisher:** CAIPEX  
**Publication:** September 2026  
**CAIPEX:** https://caipex.site/  
**DOI:** pending (to be assigned via Zenodo)

## Abstract

본 연구는 Protofelix 운영자가 공개한 LayerAI Center의 Layer 0~5 모델을 중심 사례로 삼아, 생성형 AI에 이른바 “계층형 심리(hierarchical psychological structure)”를 부여할 때 기대할 수 있는 효용과 잠재적 위험을 기술·인지과학·AI 안전·개인정보 관점에서 분석한다. 핵심 전제는 이 구조를 인간 정신의 복제나 AI의 실제 감정·의식으로 해석하지 않는 것이다. 연구는 계층 구조의 실질적 가치를 컨텍스트, 정서 신호, 기억, 가설 생성, 성찰·개선, 창작 탐색을 서로 다른 상태와 권한을 가진 모듈로 분해하는 데서 찾고, 기능적·감사 가능한 구현과 데이터·권한 거버넌스, 재현 가능한 평가 프레임워크를 제안한다.

## Scope and status

이 논문은 2026-09-24 현재 공개적으로 접근 가능한 LayerAI Center, Protofelix 공개 페이지 및 공개 Lulu 개발 로그를 분석 대상으로 한다. 비공개 소스 코드, 서버 구성, 데이터베이스, 사용자 로그, 모델 가중치 및 내부 실험 결과는 검증 대상으로 포함하지 않는다.

논문은 LayerAI를 검증된 AGI 성능 주장으로 취급하지 않고, 공개된 설계 철학과 프로토타입 개념의 기술적·안전적 함의를 분석한다.
